# LLM Powered Data Analysis Agent for Cryptocurrency Analysis

A Streamlit-based cryptocurrency data analysis and momentum analysis application.

## Run locally

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Deployment

This project is configured for Streamlit Community Cloud.

1. Upload the contents of this repository to GitHub.
2. Open Streamlit Community Cloud.
3. Create a new app from the GitHub repository.
4. Select `app.py` as the main file.
5. Deploy.

## Project Title

**LLM Powered Data Analysis Agent for Cryptocurrency Analysis**

## Notes

The application uses live cryptocurrency market-data sources where available. Do not commit API keys, passwords, access tokens, or `.env` files.
